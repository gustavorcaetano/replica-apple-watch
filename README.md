#  Sobre o Projeto

Este projeto é uma réplica de alta fidelidade da página de compra do **Apple Watch**. O foco principal foi recriar a experiência de usuário (UX) refinada da Apple, onde a interface reage instantaneamente às escolhas do cliente.

Desenvolvido como uma peça de **portfólio Front-End**, ele demonstra habilidades em manipulação de DOM, estilização avançada de componentes e estruturação limpa de código sem o uso de frameworks pesados.

---

#  Desafios e Soluções

Este projeto foi construído para demonstrar atenção aos detalhes e lógica de interface:

| Desafio | Solução Implementada |
| :--- | :--- |
| **Troca Dinâmica de Ativos** | Implementação de lógica em **JavaScript** que altera o `src` das imagens e os textos de descrição em tempo real ao selecionar uma cor. |
| **Estilização de Estados** | Uso de classes dinâmicas para gerenciar as bordas de seleção nos botões de cor e tamanho, garantindo o feedback visual clássico da marca. |
| **Fidelidade Visual** | Aplicação rigorosa de tipografia (SF Pro), espaçamentos e sombras sutis para atingir o padrão *Pixel Perfect*. |
| **Responsividade** | Adaptação completa do layout para dispositivos móveis, reorganizando a galeria e as informações de compra. |

---

#  Funcionalidades Chave

### 🔗 Seleção Inteligente
- Alternância entre cores de pulseiras com atualização imediata da galeria.
- Seleção de tamanho de caixa (41mm vs 45mm) com estados ativos.

###  Galeria Interativa
- Miniaturas que permitem a visualização de diferentes ângulos do produto.

###  Cálculo de Parcelamento
- Simulação de valores de parcelamento e desconto à vista atualizados dinamicamente.

#  Tecnologias Utilizadas (O Poder da Stack)

| Tecnologia | Função no Projeto | Por que foi escolhida? |
| :--- | :--- | :--- |
| **HTML5** | Estruturação Semântica. | Para garantir acessibilidade e uma boa base para o SEO da página. |
| **CSS3** | Layout e Design. | Uso de **Flexbox** e **CSS Variables** para facilitar a manutenção de cores e temas. |
| **JavaScript (Vanilla)** | Lógica de Interatividade. | Escolhido para demonstrar domínio da linguagem base, sem dependência de bibliotecas externas. |
| **GitHub Pages** | Hospedagem. | Facilidade de deploy e integração direta com o repositório de portfólio. |
